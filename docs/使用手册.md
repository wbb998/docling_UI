## 快速开始

### 最简单的使用方式（推荐新手）

1. **启动系统**
   - 打开浏览器访问 `http://localhost:5173`
   - 确保看到"Docling 文档处理系统"标题

2. **上传文件**
   - 点击左侧"文件上传"
   - 拖拽文件到上传区域，或点击"选择文件"
   - 支持格式：PDF、DOCX、PPTX、HTML、图片等

3. **开始转换**
   - 切换到右上角"简单模式"（推荐）
   - 点击右侧"开始执行"按钮
   - 等待处理完成

4. **下载结果**
   - 处理完成后，点击"查看结果"
   - 选择需要的格式下载（默认为Markdown）

### 5分钟快速体验
```
上传一个PDF文件 → 保持默认设置 → 点击"开始执行" → 下载Markdown结果
```

## 功能详解

### 1. 文件上传

#### 支持的上传方式
- **拖拽上传**：直接将文件拖到上传区域
- **点击选择**：点击"选择文件"按钮
- **文件夹上传**：选择整个文件夹进行批量处理
- **URL上传**：输入网络文件地址

#### 支持的文件格式
- **文档类**：PDF, DOCX, PPTX, HTML, MD, TXT
- **图片类**：PNG, JPG, JPEG, TIFF, WEBP
- **音频类**：WAV, MP3, M4A（需要ASR流水线）
- **其他**：CSV, XLSX, XML, JSON

#### 文件管理功能
- **预览**：支持文本和图片文件预览
- **重命名**：修改文件显示名称
- **移除**：从队列中删除文件
- **批量操作**：全选/全不选/批量删除

### 2. 处理模式

#### 文档转换（Conversion）
- **用途**：将文档转换为指定格式
- **输出格式**：Markdown, HTML, JSON, Text
- **适用场景**：格式转换、内容提取、结构化输出

#### 文档分块（Chunking）
- **用途**：将长文档分割成小块
- **输出格式**：JSON（固定）
- **分块策略**：
  - `by_title`：按标题分块
  - `by_page`：按页面分块
  - `by_document`：整个文档作为一块
- **适用场景**：大文档处理、向量化准备

#### 信息提取（Extraction）
- **用途**：从文档中提取特定信息
- **输出格式**：JSON（固定）
- **提取模式**：
  - 表格提取
  - 图片提取
  - 文本块提取
- **适用场景**：数据挖掘、结构化信息获取

### 3. 处理流水线

#### STANDARD 流水线（推荐）
- **适用文档**：PDF、图片、Office文档
- **处理步骤**：
  1. 文档解析（DLParse后端）
  2. OCR识别（可选）
  3. 布局分析
  4. 内容增强（表格、公式识别）
  5. 图片描述生成（可选）

#### VLM 流水线（视觉语言模型）
- **适用文档**：图片、PDF页面
- **模型类型**：
  - **本地模型**：Transformers, MLX
  - **远程API**：Ollama, LM Studio
- **优势**：更好的图像理解能力
- **注意**：需要较高的计算资源

#### ASR 流水线（语音识别）
- **适用文档**：音频、视频文件
- **模型**：Whisper系列
- **输出**：语音转文字结果

### 4. 高级功能

#### 图片描述生成
- **本地模式**：使用本地VLM模型
- **远程模式**：调用远程API服务
- **前置条件**：需要启用"远程服务"开关

#### 产物导出
- **表格导出**：CSV, HTML格式
- **图片导出**：PNG格式
- **多模态数据**：Parquet格式
- **用途**：数据分析、进一步处理

#### 后处理
- **翻译**：支持多语言翻译
- **格式化**：内容格式优化
- **清理**：去除冗余信息

### 5. 任务执行与监控

#### 任务状态
- **空闲**（IDLE）：等待开始
- **准备中**（PREPARING）：初始化处理
- **运行中**（RUNNING）：正在处理
- **已暂停**（PAUSED）：暂时停止
- **已完成**（COMPLETED）：处理成功
- **已失败**（FAILED）：处理出错
- **已取消**（CANCELLED）：用户取消

#### 实时监控
- **总体进度**：显示整体完成百分比
- **文件进度**：每个文件的处理状态
- **实时日志**：详细的处理信息
- **性能指标**：处理速度、剩余时间

#### 连接状态
- **SSE连接**：实时事件流（优先）
- **轮询模式**：定期查询状态（备用）
- **自动切换**：连接失败时自动降级

## 常见问题

### Q1: 上传文件后没有反应？
**A**: 检查以下几点：
- 文件格式是否支持
- 文件大小是否超限（建议<100MB）
- 网络连接是否正常
- 浏览器控制台是否有错误信息

### Q2: 处理速度很慢？
**A**: 可以尝试：
- 调整线程数（系统设置）
- 关闭不必要的功能（如图片描述）
- 使用STANDARD流水线而非VLM
- 减少批处理大小

### Q3: VLM模式无法使用？
**A**: 确认以下设置：
- 启用"远程服务"开关
- 配置正确的API地址
- 检查模型服务是否运行
- 网络连接是否正常

### Q4: 下载的文件格式不对？
**A**: 检查：
- 输出格式设置是否正确
- 是否选择了正确的处理模式
- 文件是否处理完成

### Q5: 任务执行失败？
**A**: 查看：
- 实时日志中的错误信息
- 文件是否损坏
- 参数配置是否有冲突
- 系统资源是否充足

## 技巧与最佳实践

### 新手建议
1. **从简单模式开始**：熟悉基本功能后再使用高级模式
2. **小批量测试**：先用1-2个文件测试，确认效果后再批量处理
3. **保持默认设置**：除非有特殊需求，否则使用默认配置
4. **关注日志信息**：出现问题时查看实时日志

### 性能优化
1. **合理设置线程数**：通常设为CPU核心数的1-2倍
2. **批量处理**：一次处理多个文件比单个处理更高效
3. **选择合适的流水线**：STANDARD > VLM > ASR（按性能排序）
4. **关闭不需要的功能**：如不需要图片描述，建议关闭

### 质量提升
1. **选择合适的模式**：
   - 格式转换 → Conversion模式
   - 长文档处理 → Chunking模式
   - 数据提取 → Extraction模式
2. **启用OCR**：对于扫描版PDF或图片文档
3. **使用VLM**：对于复杂图表和图像内容
4. **后处理优化**：根据需要启用翻译等功能

### 故障排除
1. **保存配置**：记录有效的参数配置
2. **分步调试**：逐步启用功能，定位问题
3. **查看日志**：详细的错误信息在实时日志中
4. **重置任务**：遇到问题时可以重置后重试

### 批量处理建议
1. **文件分组**：按类型或大小分组处理
2. **监控资源**：注意CPU和内存使用情况
3. **错误处理**：设置合理的错误处理策略
4. **结果验证**：处理完成后检查结果质量
