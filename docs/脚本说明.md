## 开发脚本

### 1. 端口管理脚本

#### `scripts/win/kill-port.ps1`
**用途**：强制释放指定端口，解决端口占用问题

**语法**：
```powershell
./kill-port.ps1 <端口号>
```

**示例**：
```powershell
# 释放前端端口
./kill-port.ps1 5173

# 释放后端端口
./kill-port.ps1 8000

# 释放多个端口
./kill-port.ps1 5173 8000
```

**功能特性**：
- 自动检测端口占用进程
- 强制终止相关进程
- 支持批量端口处理
- 错误处理和日志记录

**源码解析**：
```powershell
param(
    [Parameter(Mandatory=$true)]
    [int[]]$Ports
)

foreach ($Port in $Ports) {
    Write-Host "正在检查端口 $Port..." -ForegroundColor Yellow
    
    # 查找占用端口的进程
    $processes = Get-NetTCPConnection -LocalPort $Port -ErrorAction SilentlyContinue
    
    if ($processes) {
        foreach ($process in $processes) {
            $pid = $process.OwningProcess
            Write-Host "发现进程 PID: $pid 占用端口 $Port" -ForegroundColor Red
            
            try {
                Stop-Process -Id $pid -Force
                Write-Host "已终止进程 PID: $pid" -ForegroundColor Green
            }
            catch {
                Write-Host "无法终止进程 PID: $pid - $($_.Exception.Message)" -ForegroundColor Red
            }
        }
    }
    else {
        Write-Host "端口 $Port 未被占用" -ForegroundColor Green
    }
}
```

#### `apps/web/scripts/start-dev.ps1`
**用途**：启动前端开发服务器，自动处理端口冲突

**功能**：
1. 自动释放5173端口
2. 安装/更新依赖包
3. 启动Vite开发服务器
4. 错误处理和重试机制

**源码**：
```powershell
# 设置错误处理
$ErrorActionPreference = "Stop"

Write-Host "=== 启动前端开发服务器 ===" -ForegroundColor Cyan

try {
    # 1. 释放端口
    Write-Host "1. 释放端口 5173..." -ForegroundColor Yellow
    ../../../scripts/win/kill-port.ps1 5173
    
    # 2. 检查依赖
    Write-Host "2. 检查依赖包..." -ForegroundColor Yellow
    if (!(Test-Path "node_modules")) {
        Write-Host "安装依赖包..." -ForegroundColor Yellow
        npm install
    }
    
    # 3. 启动服务
    Write-Host "3. 启动开发服务器..." -ForegroundColor Green
    npm run dev
}
catch {
    Write-Host "启动失败: $($_.Exception.Message)" -ForegroundColor Red
    exit 1
}
```

#### 常用函数库
```powershell
# 日志函数
function Write-Log {
    param([string]$Message, [string]$Level = "INFO")
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    Write-Host "[$timestamp] [$Level] $Message"
}

# 进度显示函数
function Show-Progress {
    param([int]$Current, [int]$Total, [string]$Activity)
    $percent = [math]::Round(($Current / $Total) * 100, 2)
    Write-Progress -Activity $Activity -Status "$Current/$Total ($percent%)" -PercentComplete $percent
}

# 错误处理函数
function Handle-Error {
    param([string]$ErrorMessage, [bool]$Exit = $true)
    Write-Log $ErrorMessage "ERROR"
    if ($Exit) { exit 1 }
}
```

}

## 故障排除

### 常见问题

#### 执行策略错误
```
无法加载文件，因为在此系统上禁止运行脚本
```
**解决方案**：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

#### 权限不足
```
拒绝访问
```
**解决方案**：
- 以管理员身份运行PowerShell
- 检查文件和目录权限

#### 模块缺失
```
找不到模块
```
**解决方案**：
```powershell
Install-Module -Name ModuleName -Force
```
